# Быстро поднять тестовый стенд

Актуальная ветка: **temp/reviews-validation**. Если скачал её целиком, исходники уже содержат все исправления. Последнее обновление добавляет инструкции — заново менять код ради этих инструкций не нужно.

Список исправлений и точных файлов: [CHANGES_AND_FILES.md](CHANGES_AND_FILES.md).

## 1. Сохрани свои настройки

Самый быстрый путь — использовать свой уже настроенный проект и конфигурации IDEA. При переносе исходников объединяй папки, не удаляй проект целиком. Оставь свою папку `local-run`, пароли и ключи.

Если открываешь свежераспакованный ZIP как новый проект, перенеси **всю свою прежнюю `local-run`** в его корень. В ней должны остаться `linux-database.json`, `secrets/` и файлы окружения. Не создавай новые ключи только для Documents. После переноса повтори шаг 2: он обновит абсолютные пути в файлах окружения под новую папку проекта. В IDEA затем заново вставь значения из полученных env.txt.

## 2. Подготовь существующие БД и примени миграцию отзывов

Команды ниже — для твоего **CachyOS**, уже установленного PostgreSQL и DejaVu. Выполняй из корня проекта, где находится `pom.xml`, обычным пользователем:

```bash
sudo systemctl start postgresql
bash scripts/linux/prepare-local.sh --pg-port 5432 --font-path /usr/share/fonts/TTF/DejaVuSans.ttf
```

Используй **свой прежний** порт, хост и `--database-prefix`, если менял их при первоначальной подготовке. Если раньше использовал `--password-auth`, `--no-sudo` или другие параметры подключения, повтори прежнюю команду с ними. Не подставляй 5432 вместо своего реального порта.

Скрипт сохраняет существующие базы/роль/пароль/ключи и применяет недостающие миграции. Для отзывов необходим файл `local-stack/migrations/ride/002_reviews.sql`. Повторный запуск на той же базе допустим. Без миграции новый Ride не сможет читать историю поездок. Скрипт не устанавливает программы, не создаёт системный PostgreSQL-кластер и не запускает Tomcat.

На CachyOS пакет шрифта — `ttf-dejavu` (`sudo pacman -S --needed ttf-dejavu`), не apt. Проверить путь: `pacman -Ql ttf-dejavu | grep '/DejaVuSans.ttf$'`. Для новой установки окружения см. [Linux-подготовку](docs/UBUNTU_NO_DOCKER.md), учитывая, что команды установки apt в том документе относятся только к Ubuntu.

## 3. Собери артефакты

Для последнего обновления с публичными отзывами и обработкой служебной навигации пересобери **все шесть приложений**. Если скачал полный ZIP, исходники уже обновлены, но WAR нужно собрать локально.
В IDEA сделай Maven Reload и `package` у нужных модулей. Либо одной командой из корня проекта (Bash вызывается явно, команда работает и из Fish):

```bash
bash -c 'for module in . services/user services/moderation services/scooter services/ride services/documents; do mvn -f "$module/pom.xml" -DskipTests package || exit; done'
```

Нужны Maven и JDK 17. Здесь `-DskipTests` используется для быстрой сборки стенда; проверка поведения выполняется ниже и по полному чек-листу. Если Maven не скачал зависимости, сборка не завершена — не разворачивай старый WAR как новый.

| Приложение | Собранный WAR | Порт | Environment variables в IDEA |
| --- | --- | --- | --- |
| User | `services/user/target/user-service.war` | 8081 | `local-run/user.env.txt` |
| Moderation | `services/moderation/target/moderation.war` | 8082 | `local-run/moderation.env.txt` |
| Scooter | `services/scooter/target/scooter.war` | 8083 | `local-run/scooter.env.txt` |
| Ride | `services/ride/target/ride-service.war` | 8084 | `local-run/ride.env.txt` |
| Documents | `services/documents/target/documents.war` | 8085 | `local-run/documents.env.txt` |
| BFF | `target/scooter-bff.war` | 8080 | `local-run/bff.env.txt`; дополнительно `local-run/bff.vmoptions.txt` в VM options |

## 4. Запусти свои шесть конфигураций IDEA

В каждой конфигурации должен быть **свой сервис**, порт из таблицы, его env.txt и Application context **`/`**. Рекомендуемая проверенная комбинация: JDK 17 / Tomcat 10.1. Каждой конфигурации нужен отдельный CATALINA_BASE; дополнительные JMX/shutdown-порты тоже не должны конфликтовать.

Если используешь WAR exploded из модулей, пересобери именно его перед развёртыванием. Если используешь External Source WAR — выбери новый файл из таблицы, а не WAR из прежней папки Downloads. Полностью останови и запусти изменённые сервисы.

Порядок запуска: **User → Moderation → Scooter → Ride → Documents → BFF**. Дождись завершения развёртывания каждого приложения. Сервисам может требоваться другой сервис для первых запросов; проверку начинай после запуска всех шести.

Самые важные проверки настроек:

- В `DB_URL` каждого сервиса указана **его** БД: `_user`, `_moderation`, `_scooter`, `_ride`, `_documents`, с твоим прежним префиксом. Moderation не должен указывать на Documents.
- У User — private.pem и public.pem из одного комплекта. У Documents `JWT_PUBLIC_KEY_PATH` — абсолютный путь к **этому же public.pem**, начиная с `/home/...`, а не `home/...`.
- `PDF_FONT_PATH` у Documents ведёт к существующему TTF с кириллицей.
- `SERVICE_API_KEY` одинаковый у Scooter и Ride; `PAYMENT_MODE=educational` у Ride.
- Адреса сервисов: User 8081, Moderation 8082, Scooter 8083, Ride 8084, Documents 8085; вход BFF `http://localhost:8080/login.jsp`.

Файлы `*.env.sh` предназначены для Bash, их не нужно вставлять как NAME=value в IDEA или source-ить прямо в Fish. В IDEA используй `*.env.txt`. Для запуска из терминалов нужны отдельные Bash-сеансы с env.sh **соответствующего** сервиса и отдельными CATALINA_BASE; не запускай все сервисы с одной общей средой и одним Tomcat base.

## 5. Быстрая проверка за один проход

1. Открой `http://localhost:8080/`, нажми **Ctrl+Shift+R**. На 8081/8082/8084 при навигации браузера ожидается служебная HTML-страница 403; у 8083/8085 может быть HTML-404. Проверять API нужно через Postman/curl с Accept: application/json; пользовательский сайт — 8080.
2. Зарегистрируй тестового пользователя: полное имя с правильным форматом, дата рождения не моложе 16 лет. Проверь вход и профиль.
3. Разреши геолокацию: показаны ближайшие свободные самокаты. Затем в отдельном профиле/инкогнито запрети: доступен общий каталог без расстояний, поездку на READY начать можно.
4. Начни поездку, заверши, оплати. Без геолокации завершение требует явного подтверждения сохранённой позиции. При стандартном тарифе минимальная сумма — 58 ₽, оплата учебная, реальных денег не списывает.
5. Оставь отзыв с двумя оценками, обнови страницу: отзыв сохранился. Скачай чек и историю PDF, открой их и проверь кириллицу.
6. Для проверки админки подготовь отдельный ADMIN по [инструкции](ADMIN_LOGIN.md). Вход через `http://localhost:8080/login.jsp` должен вести на `http://localhost:8082/admin/users.html`. Проверь блокировку/разблокировку тестового USER и выход.
7. После этого иди по [331 пункту](docs/FULL_API_URL_CHECKLIST.md), отмечая результат в [CSV](docs/FULL_API_URL_CHECKLIST.csv). При ошибке сохраняй ID проверки, HTTP-ответ и Caused by из лога, без паролей и токенов.
