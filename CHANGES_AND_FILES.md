# Изменения и файлы

Актуальный код — `37dc8e3`, ветка `temp/reviews-validation`. Следующие коммиты инструкций не меняют поведение приложений.

- Регистрация 16+, проверка формата ФИО в браузере, BFF и User.
- Автоматическая геолокация, ближайшие READY из БД; X — долгота, Y — широта, расстояние в метрах/километрах.
- При отказе GPS — общий каталог без расстояний, старт по позиции самоката из БД, завершение по сохранённой позиции только с подтверждением.
- Отзывы о завершённых поездках и самокатах: две оценки 1–5, комментарии, редактирование, сохранение в Ride DB.
- Реальные анонимные отзывы на главной: последние два, окно со страницами по 20, пустое состояние/ошибка/повтор; старые демонстрационные отзывы удалены.
- Исправлен вход по действующей BFF-сессии: USER открывает кабинет, ADMIN панель, повторный GET login.jsp не отзывает токен.
- При вводе служебного API-адреса в браузере — 403 HTML со ссылкой на сайт. Сам API отдельно проверяет роль и владельца данных, вызовы интерфейса и Postman не блокируются.
- Улучшена диагностика RSA-ключа Documents, сохранена проверка JWT; убраны лишние пояснения в пользовательском интерфейсе. Оплата остаётся учебной.
- Обновлён чек-лист: 331 пункт, 60 операций API, CSV и Postman.

Точные рабочие пути перечислены в [CHANGED_RUNTIME_FILES.txt](CHANGED_RUNTIME_FILES.txt): отдельно последнее обновление поверх 930306f и все изменения поверх cfe0bf6. Если скачан полный свежий ZIP, нужные исходники уже внутри.

Для последнего обновления пересобрать **все шесть сервисов**. Переменные и ключи local-run оставить свои. Новых переменных и SQL-миграций в последней правке нет; ранее добавленная 002_reviews.sql должна быть применена.
