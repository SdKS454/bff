# Полная ручная проверка к сдаче: версия с GPS

Это чек-лист для локального прогона пользователем. Пустая строка результата означает **ещё не проверено**, а не PASS. Выполнять на тестовых аккаунтах. Перед проверками с остановками сохранить нужные данные/ключи и не удалять рабочие БД.

**Перед началом:** сначала применить GPS-правку и пересобрать BFF + Scooter. Эти проверки относятся к GPS-версии, а не к старому интерфейсу с X/Y. Старые точки условной сетки нужно заменить реальными GPS-точками выбранного города или использовать явную тестовую позицию браузера рядом с известными точками.

Для GUI-сценариев нужны два обычных пользователя и ADMIN в разных профилях браузера. Негативные запросы и отказы сервисов проверять только на своём локальном стенде. Если сценарий не проходит, зафиксировать фактический результат: это задача на исправление, а не повод поставить PASS.

## Адреса готовности

| Компонент | Проверка без входа | Ожидается |
|---|---|---|
| BFF :8080 | / | 200, интерфейс ScootX |
| User :8081 | /api/users/exists?login=qa.user1 | 200, JSON exists |
| Moderation :8082 | /admin/users.html | Страница панели, затем вход при отсутствии токена |
| Scooter :8083 | /api/scooters | 401 без Bearer |
| Ride :8084 | /api/rates | 401 без Bearer |
| Documents :8085 | GET /api/documents/generate | 405: endpoint принимает POST |

Корневой / у отдельного микросервиса может возвращать 404: это не проверка его работоспособности. У пользователя PostgreSQL сейчас 127.0.0.1:7689. На машине преподавателя следует брать его фактический порт.

## Как фиксировать ошибки

Для каждого FAIL запиши номер пункта, время, роль/тестовый логин, шаги, ожидаемое и фактическое поведение. Приложи код/тело ответа из Network без Authorization/Cookie, свежий блок Exception/Caused by из нужного localhost*.log и скриншот без паролей/токенов. Укажи версии JDK, Tomcat и PostgreSQL.

Приёмка не завершена, если не работает хотя бы один основной путь: регистрация/вход, nearest GPS, старт/finish/pay, PDF, ban/unban, чужие права или сохранность данных. Непроверенные сложные сценарии отмечать отдельно; этот список не заменяет фактический запуск.
