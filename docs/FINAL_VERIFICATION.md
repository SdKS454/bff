## Результаты

- Maven verify всех шести приложений — успешно. 346 Java-тестов, включая 13 HTTP-тестов User с настоящей PostgreSQL.
- JavaScript API — 8 тестов успешно; Chromium — 31 сценарий успешно. Браузерные сценарии используют настоящий BFF WAR и HTTP-фикстуры зависимостей.
- На настоящих шести сервисах: создание/вход USER и ADMIN, проверка ролей/чужого доступа, сохранение сессии при login.jsp, служебная HTML-навигация, старт/позиция/завершение/учебная оплата, бан во время активной поездки, разрешённое завершение/оплата при бане, запрет нового старта, отзыв/публичная лента и unban — успешно.
- Сформированы все три вида настоящих PDF: чек, история, уведомление о блокировке. Проверены PDF-заголовок/тип и извлечение русских букв из каждого документа.
- Полный автоматический путь stand.py: подготовка пяти новых БД, сборка dist, запуск всех шести JVM, status, создание USER/ADMIN и повторное выполнение demo, остановка — успешно.
- Подготовка проверена на отдельном локальном PostgreSQL через --no-sudo; стандартный sudo-режим описан для установленного системного PostgreSQL. Повторная подготовка, перенос с сохранением ключей/реквизитов в папку с кириллицей и пробелами, повторный запуск и сохранность отзыва после перезапуска — успешно.
- Негативные проверки: занятый порт, изменённые исходники, повреждённый WAR, параллельная команда и неуспешный запуск при недоступном User DB — отклоняются без запуска смешанной/устаревшей версии. demo без управляемого стенда отклоняется.
- PowerShell-скрипт подготовки прошёл синтаксическую проверку PowerShell 7. **Полный Windows-запуск в этой Linux-среде не выполнялся**; Windows-путь реализован и описан, но не заявляется как проверенный на Windows.

Финальная проверка извлечённого ZIP: на ещё пяти новых БД запущены все шесть сервисов из папки с кириллицей/пробелами, созданы два USER и ADMIN, повторены реальные поездка/бан/оплата/отзыв и все три PDF. Первый PDF проверен после исправления холодного кэша: кэш PDFBox/fontconfig создаётся в рабочей папке и сохраняется, BFF допускает генерацию до 60 секунд. Добавлен HTTP-регрессионный тест с ответом PDF после 11 секунд, который на старом 10-секундном тайм-ауте завершался бы ошибкой.

Полный ручной список — 331 пункт/60 API. Это отдельный план для преподавателя: его пустые поля результатов не означают, что все 331 пункта вручную выполнены. Успешные автоматические проверки перечислены выше.

## Пределы проекта

Оплата учебная, реальных списаний/банковского провайдера нет. Избранное хранится по userId в браузере, профиль доступен для просмотра. Без геолокации последняя сохранённая позиция не подтверждает фактическую парковку. Страница отказа API-навигации не заменяет проверки JWT/роли/владельца; публичные отзывы доступны без JWT и не содержат идентификаторов пользователя/поездки. Это локальный стенд, HTTP слушает loopback, браузер открывается на той же машине.
