# Проверка запуска без Docker — 27 октября 2026

Добавлены scripts/windows/prepare-local.ps1 и инструкция WINDOWS_NO_DOCKER.md.
Скрипт создаёт отдельные PostgreSQL БД с префиксом kicksharing_, применяет схемы
и миграции, создаёт RSA/служебный ключи и сохраняет реальные настройки всех
шести приложений в local-run/. Он не устанавливает программы и не запускает Tomcat.

## Что проверено фактически

Среда проверки: Linux, PowerShell 7.5.2, нативный PostgreSQL 17.11, Java 17,
шесть отдельных нативных Tomcat 10.1.61. Docker при этих проверках не использовался.
WAR-файлы содержат ту же реализацию сервисов, что в версии a254b97: Java/JS-код
приложений при добавлении этого способа запуска не менялся.

- Парсер PowerShell: скрипт разбирается без ошибок.
- Первый запуск: пять новых БД, схемы, примеры, версии миграций, три файла ключей,
  шесть наборов переменных и BFF VM options — успешно.
- Повторный запуск после поездки: ключи побайтово сохранены, зарегистрированные
  пользователи, оплаченная поездка, документы и версии миграций сохранены.
- Неверный пароль PostgreSQL, отсутствующий шрифт и чужая/неполная схема:
  подготовка отклонена; таблица-маркер посторонней БД и данные проекта сохранены.
- Изменённый SHA-256 применённой миграции: транзакция отклонена; пользователи
  и оплаченная поездка сохранены. Тестовое изменение контрольной суммы восстановлено.
- После успеха и ошибки прежнее значение PGPASSWORD вызывающего процесса восстановлено.
- Сгенерированные настройки непосредственно использованы шестью Tomcat: правильные
  JDBC-адреса, общие ключи, шрифт, корневые контексты и адреса зависимостей.
- scripts/check-native-stack.cjs — PASS: регистрация, User/Moderation, nearest,
  position и запрет чужого изменения, finish/pay, PDF-чек/история, снимок документа,
  запрет чужого скачивания, soft delete, logout/отзыв JWT.
- local-run исключён из Git и Docker build context; пароли/ключи не опубликованы.

Сценарий проверки native требует только Node.js 22+ дополнительно к уже запущенному
стенду. Основной запуск и ручная проверка Node.js не требуют.

## Граница проверки

Windows в этой облачной среде нет. Реальный прогон выполнен PowerShell 7 на Linux;
скрипт написан для синтаксиса Windows PowerShell 5.1+ без специфичных команд Linux.
Автопоиск Windows Program Files, Windows-служба PostgreSQL и конфигурации IDEA
проверяются на компьютере пользователя по WINDOWS_NO_DOCKER.md.
В облаке использован LiberationSans с кириллицей; на Windows указывается
фактический локальный Arial/DejaVuSans TTF.

GitHub Actions дополнен проверкой первого/повторного запуска подготовки через
PowerShell с PostgreSQL. Фактический удалённый статус смотрите в Actions.
