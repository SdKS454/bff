# ride: запуск в составе локального стенда

Каноническая версия сервиса находится в этом каталоге. Запуск/порты/БД/ключи:
[единая инструкция](../../local-stack/README.md).
Фактический API: [REST-контракты](../../docs/API_CONTRACTS.md).
Изменения и сквозная проверка: [отчёт](../../docs/STACK_INTEGRATION.md).

Из корня репозитория `docker compose up --build -d` запускает все приложения.
Для ручной сборки этого сервиса используйте `mvn clean verify` из этого каталога,
Java 17+ и отдельный Tomcat 10.1 с контекстом `/`.
